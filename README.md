# DPP-Project-Simple

## Digital Product Passport & ML Circularity Assessment System

A complete student-friendly prototype with Docker deployment support!

---

## 🚀 Running with Docker (Recommended)

1. Open your terminal in the root folder (`digital-product-passport`).
2. Run from the project root:
   ```bash
   docker compose up --build
   ```
3. Open the frontend at `http://localhost:5173`.
4. Open the backend API documentation at `http://localhost:8000/docs`.

To stop the services, run:

```bash
docker compose down
```
